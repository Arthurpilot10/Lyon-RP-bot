# Bot RP Banque / Police / Entreprise

Sans emojis.

## Installation
```bash
npm install
cp .env.example .env
npm run deploy
npm start
```

## Commandes
- `/salaire`
- `/solde`
- `/virement`
- `/amande-mettre`
- `/pds`
- `/fds`
- `/entreprise-cree`
- `/entreprise-liste`
- `/entreprise-prendre`
- `/devis`
- `/devis-accepter`
- `/devis-refuser`
- `/admin-ajouter-argent`
- `/admin-enlever-argent`

Modifie `src/config.js` avec tes noms de rôles exacts.
